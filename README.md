# Users Data Fetch Project

This is a simple JavaScript project that fetches users data from an API and displays the users in cards.

## Features

- Fetch users data from API
- Uses `async/await`
- Uses `try...catch...finally`
- Displays loading message while fetching data
- Creates user cards dynamically
- Shows:
  - Name
  - Username
  - Email
  - Phone
- Hover effect for cards
- Responsive card layout
